### 2-2 セキュリティーの穴が一気に広がる
もしAIが生成したコードに脆弱性があったとしよう。それが複数の場所にコピーさえされていれば、セキュリティーの穴が一瞬で会社全体に広がることになる。
さらに深刻なのがライセンスの問題だ。AIが学習したもののコードには、GPLなどの厳しい利用条件がついていることがある。気づかずに使ってしまうと、「自社のプログラムもソースコードを公開しなければならない」という義務が発生することもある。
